# 社区版维护

- 维护状态：维护中
- 目标读者：社区部署者与贡献者
- 事实来源：API 路由注册、Web 路由、共享模型契约、根目录 npm 脚本

## 概述

SoftJL Community 使用独立源码快照和全新提交历史，保留需求到工程说明书的完整流程。README 延续原项目的双语介绍、Logo、徽章、截图和表格。

## 当前设计或配置

保留需求规则提取与确认、系统环境图、业务与系统流程图、实现方案、全部需求模型、全部设计模型、测试与覆盖、三类工程说明书、图表编辑导出、项目成员、任务历史与重试，以及自带模型配置。

排除平台计费与支付、充值额度和运营后台。MCP 与 Coding Agent 只读集成为可选能力，连接页复用完整版，授权默认选择项目，账号范围须明确选择。账户认证、项目角色权限、供应商密钥保护和生成遥测属于核心运行能力，继续保留。

### 项目模式与本次同步

社区版 v2.1.0 同步官网已提交版本 `6866919` 的适用功能，保留社区仓库独立历史。新项目默认普通版，已有项目按专业版处理；模式创建后不可切换，与收费无关。普通版持续会话支持需求澄清、八类图表、指定图修改、测试与两类说明书；专业版保留原有阶段、可行性、依赖、追踪和覆盖流程。

需求规则采用共享的版本快照与稳定标识，替代旧的规则审核与自动修复交互；手动修订、需求来源和下游过期检查仍保留。工作区写回增加版本守卫，运行记录补充 Token 统计与失败原因。普通版会话和图表写入项目工作区，内部会话记录不向浏览器或 MCP 暴露。

模型容量与能力由后台公开目录缓存提供，失败时保留成功缓存。目录仅提供模型参考，不提供托管模型或密钥，也不会新增运营管理接口。社区版不包含官网管理员补充容量的页面；未知容量使用界面标注的当前预算，不能当作供应商承诺容量。

## 操作与维护

社区版在自己的服务与独立数据库中运行，不用于直接降级完整版数据库。先配置模型供应商，完成连接测试，再按需求、可行性、模型、测试与说明书的依赖顺序生成。

使用根目录开发脚本在本机体验。生产部署需自行设置数据库、域名、邮件、模型凭据加密与文档服务，关闭开发访客；模型生成统一使用账户中保存并加密的供应商配置。仓库不提供原站点自动生产发布工作流。

同步完整版变更时，检查导入、页面入口、后台接口、依赖和迁移，防止重新引入排除能力。发布只提交源码、必要静态资源和锁文件；不复制旧 Git 历史、本机配置、运行数据或密钥。

### 升级与持久化

升级前备份社区数据库、文档目录与供应商加密密钥，将 Node.js 更新到 22.19.0 或更高版本，再安装新锁文件依赖并重新构建。社区版 Agent 使用维护命名空间的 Pi SDK 1.3.0，补充验证系统消息、上下文编辑及压缩记录的会话恢复。启动时执行项目模式与遥测索引迁移，保留既有社区 MCP 授权迁移标识。已有项目默认专业版，不会自动改成普通版；数据库仍须与官网版独立。

普通版对话、图表、项目约定与继续生成信息跟随项目工作区保存，长期使用须配置 PostgreSQL。配置 `UML_MODEL_CATALOG_DIR` 可将模型目录缓存放入持久目录；当前由单 API 实例管理。`UML_STANDARD_CONTEXT_TOKENS` 可降低会话预算，未知容量时默认预算为 48,000 Token。开发环境可通过本地环境变量显式设置 `UML_DEMO_PROVIDER_SEED=true` 启用演示供应商初始化，普通启动不自动创建供应商；密钥不得提交。

版本与发布说明维护在中英文 README 和 GitHub Release。Release 源码包从社区仓库的最终提交生成，提供 ZIP、tar.gz、`release.json` 与 `SHA256SUMS`，不包含依赖、本机配置或运行数据。

### 精简边界

社区版不提供考试占位页、支付文案或旧 Vite 启动与预览链路；前端统一使用 Next.js。依赖旧静态构建清单的搜索提交脚本一并移除，当前爬虫文件由 Next.js 输出。未被业务引用的后台工具与模板示例不再随源码维护。

案例建项目接口、课程绑定和站内公告仍保留，以兼容已有调用和数据。账户角色、项目成员、供应商调用限额与生成遥测继续维护。

离线演示仅由部署者配置的项目 ID 或名称匹配启用，使用 `UML_DEMO_OFFLINE_PROJECT_IDS` 或 `UML_DEMO_OFFLINE_PROJECT_NAME_PATTERNS`。普通启动不配置这些变量；固定演示产物在命中演示项目后才加载，已有演示任务仍可继续使用保存的演示标记。

社区版不包含官网宣传首页、专用模板与图片。根地址 `/` 直接跳转项目列表 `/projects`，未登录用户进入登录流程；登录页不再提供返回官网入口。所有应用页面禁止搜索索引，站点地图不再发布页面地址，也不再输出首页结构化数据，参见 [SEO 运维](../deployment/seo.md)。导出资料或启用 MCP 后，可连接编程助手在自己的仓库实现与验证。

## 验证

运行共享包与应用构建、契约/API/Web/渲染测试和文档检查。边界回归测试确认排除接口返回 404，核心工程路由仍被注册；可行性、模型、文档和重试使用原有流程测试验证。

前端类型检查覆盖业务源码与测试夹具，生产构建保留 Next.js 默认的类型检查。CI 单独运行前端及评估工具包的类型检查，并覆盖提示词、开发辅助和部署脚本测试。浏览器检查复用同一份隔离站点构建。真实模型调用和 OnlyOffice 在线编辑还需要部署者在自己的配置下验收。
