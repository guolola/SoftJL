# 社区版维护

- 维护状态：维护中
- 目标读者：社区部署者与贡献者
- 事实来源：API 路由注册、Web 路由、共享模型契约、根目录 npm 脚本

## 概述

SoftJL Community 使用独立源码快照和全新提交历史，保留需求到工程说明书的完整流程。README 延续原项目的双语介绍、Logo、徽章、截图和表格。

## 当前设计或配置

保留需求规则提取与确认、系统环境图、业务与系统流程图、实现方案、全部需求模型、全部设计模型、测试与覆盖、三类工程说明书、图表编辑导出、项目成员、任务历史与重试，以及自带模型配置。

排除平台计费与支付、充值额度和运营后台。MCP 与 Coding Agent 只读集成为可选能力，连接页复用完整版，授权默认选择项目，账号范围须明确选择。账户认证、项目角色权限、供应商密钥保护和生成遥测属于核心运行能力，继续保留。

## 操作与维护

社区版在自己的服务与独立数据库中运行，不用于直接降级完整版数据库。先配置模型供应商，完成连接测试，再按需求、可行性、模型、测试与说明书的依赖顺序生成。

使用根目录开发脚本在本机体验。生产部署需自行设置数据库、域名、模型凭据加密与文档服务，关闭开发访客；模型生成统一使用账户中保存并加密的供应商配置。仓库不提供原站点自动生产发布工作流。

同步完整版变更时，检查导入、页面入口、后台接口、依赖和迁移，防止重新引入排除能力。发布只提交源码、必要静态资源和锁文件；不复制旧 Git 历史、本机配置、运行数据或密钥。

### v2.2 核心对齐与优化

当前社区版支持普通项目持续对话、专业工作流的任务上下文选择、模型会话修复、独立分支并行、失败实例重试与实际 Token 展示。普通版和专业版是项目流程模式，均支持自带模型；名称不表示付费档位。

模型结构、引用与来源映射使用同一任务会话和共享五次修复预算，保留原始消息及历次输出，返回完整修正结果；渲染阶段继续原会话并继承已消耗预算，分支独立维护后续历史，模型、映射与绘图通过后一起发布。映射按模型中真实存在的元素 ID 校验，不再使用置信度或待确认字段。上下游及间接依赖不能同批生成，卡片、全选、操作守卫与 API 共同执行限制；用例来源变化会让已有分析模型及关联下游标记为待更新。需求模型的连续预览与可行性分支成果及时发布，实际人工修改仍触发保护。矩阵按全部范围元素展示映射率，分析模型总览和单图复用同一来源口径。

普通项目按本轮确认的范围生成图表，持续会话按容量压缩，后续修改限于指定图表。专业项目保留来源与依赖检查，模型修复严格隔离当前任务；实现方案和文档章节的局部补丁校验目标和基础版本，成功产物无需随失败项重做。文档改为内置 DOCX 预览和下载，不再使用 OnlyOffice 编辑链路。

社区数据库直接使用官网当前 `current_platform_schema_v3` 安装基线，不再保留旧迁移链或历史模型格式兼容。首次部署配置空数据库后初始化，已采用该基线的数据库可继续使用；v1、v2 及旧迁移记录会被拒绝，不执行历史修补 SQL。组织、课程、班级、团队及其关联字段、权限和配额已移除；项目仅对已加入的成员开放，通过成员邀请协作。项目模式是必填字段，新建项目明确选择普通版或专业版。

供应商配置使用列表展示状态、默认模型、更新时间和单一启用项，个人配置的编辑与删除仅对所属用户开放。发现模型时执行能力探测，保存时复用已发现结果并验证地址安全，避免重复测试调用；模型搜索展示品牌与输出模式。工作台偏好独立保存，不覆盖供应商选择草稿。旧来源映射元数据不自动转换，工作区必须符合当前契约。

`npm run benchmark:generation` 对固定合成样本测量本地输入分词，不调用远端模型。样本结果、边界和升级要求见[当前发布说明](../../release-notes.md)；线上总耗时和总消耗必须在相同项目、模型、供应商及并发条件下另行对照。

### 精简边界

社区版不提供考试占位页、支付文案或旧 Vite 启动与预览链路；前端统一使用 Next.js。依赖旧静态构建清单的搜索提交脚本一并移除，当前爬虫文件由 Next.js 输出。未被业务引用的后台工具与模板示例不再随源码维护。

案例建项目接口和站内公告仍保留。账号改为用户名注册、登录和邀请；通知中心统一处理项目邀请、个人已读及移除状态，提供默认头像选择。项目列表使用可展开卡片预览资料，快速建模的上下文占用按当前会话和实际预算计算，单次调用明细单独展示。快速建模的每条已接受消息保存独立任务记录，仅归属本轮变化的图表、测试和文档，项目历史可查看本轮成果。账户角色、项目成员、供应商调用限额与生成遥测继续维护。

离线演示仅由部署者配置的项目 ID 或名称匹配启用，使用 `UML_DEMO_OFFLINE_PROJECT_IDS` 或 `UML_DEMO_OFFLINE_PROJECT_NAME_PATTERNS`。普通启动不配置这些变量；固定演示产物在命中演示项目后才加载，已有演示任务仍可继续使用保存的演示标记。

社区版不包含官网宣传首页及其专用资源；保留普通项目输入区、项目空状态和工作区引导所需的模板与静态资源。根地址 `/` 直接跳转项目列表 `/projects`，未登录用户进入登录流程；登录页不再提供返回官网入口。所有应用页面禁止搜索索引，站点地图不再发布页面地址，也不再输出首页结构化数据，参见 [SEO 运维](../deployment/seo.md)。导出资料或启用 MCP 后，可连接编程助手在自己的仓库实现与验证。

## 验证

运行共享包与应用构建、契约/API/Web/渲染测试和文档检查。边界回归测试确认排除接口返回 404，核心工程路由仍被注册；可行性、模型、文档和重试使用原有流程测试验证。

前端类型检查覆盖业务源码与测试夹具，生产构建保留 Next.js 默认的类型检查。CI 单独运行前端及评估工具包的类型检查，并覆盖提示词、开发辅助和部署脚本测试。浏览器检查复用同一份隔离站点构建。真实模型工具调用、生成质量与 DOCX 内置预览还需要部署者在自己的配置下验收。
