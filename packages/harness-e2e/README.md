# 端到端测试工具包

## 职责

在 Chromium 中验证生产 Web 构建的导航、布局、生成交互和响应性能，并输出便于定位问题的测试证据。

## 边界

本包启动 Web 服务，并用测试夹具模拟 API 响应和事件流。它验证浏览器交互与接口契约的衔接，不覆盖真实供应商调用、数据库或跨服务部署，也不替代各应用和共享包的单元测试。

## 使用或常用命令

```bash
npm run test:harness-e2e
```

默认先构建测试专用站点，再启动独立 Web 服务；不复用已经运行的服务。

## 配置

测试使用固定的隔离站点来源。CI 已用相同来源构建生产 Web 时，可以设置 `PLAYWRIGHT_SKIP_BUILD=1` 复用产物，避免重复构建。配置应使用专用测试变量，禁止提交真实账号、密钥或生成产物。

## 验证

先完成共享契约构建，再运行端到端测试并检查所有场景及证据输出。
