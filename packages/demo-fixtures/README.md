# 演示场景数据

## 职责

提供后端离线演示与前端测试共同使用的冻结场景数据和类型。

## 边界

只依赖共享契约，不读取任何应用内部模块。场景保留已记录的模型、来源和快照，加载时不迁移或补造数据。

## 使用或常用命令

在仓库根目录运行 `npm run build:demo-fixtures`，或通过 `npm run build:packages` 按依赖顺序构建。

## 配置

演示数据经公共包入口提供；冻结数据沿用现有编码，未生成额外二进制资源。生产 API 发布包包含本工作区的编译产物。

## 验证

通过 API 离线演示测试、共享契约校验和前端场景测试验证相同数据的消费者。
