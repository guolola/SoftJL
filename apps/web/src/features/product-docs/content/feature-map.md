# 页面入口与工作流程

## 适用场景

知道自己想做什么，但不确定去哪个页面；或想了解某个结果的来源和下一步用途。

## 入口位置

- [项目首页](/projects)：创建或打开项目。
- 项目左侧 **项目导航**：进入需求、分析、建模、测试和说明书。
- 项目左侧 **项目管理**：打开 **链路图、运行历史、项目设置、成员、文档中心**。
- 项目顶部：查看生成状态并打开 **生成任务** 抽屉。
- [使用文档](/tutorial)：无需登录即可阅读。

![需求页面的阶段导航与主内容区](/help/images/docs-requirements-current.png)

## 前置条件

阅读文档无需登录。操作项目需要登录并拥有项目权限；生成内容还需满足当前页面列出的前置条件。

## 操作步骤

先按下面的任务表找到入口，再阅读对应指南。

| 想做的事 | 去哪里 | 阅读指南 |
| --- | --- | --- |
| 建立项目、邀请协作者 | 项目首页、侧栏成员入口 | [项目管理](project-drawers.md) |
| 把文字整理为可检查的规则 | 系统需求 | [需求规则](requirements.md) |
| 评估边界、业务流程和实现路线 | 可行性分析 | [可行性分析](feasibility-analysis.md) |
| 生成角色、实体与流程图 | 需求模型 | [需求 UML](uml-models.md) |
| 细化架构、页面和数据库 | 设计模型 | [设计模型](design-models.md) |
| 生成检查清单和测试场景 | 测试 | [测试覆盖](testing-coverage.md) |
| 导出正式文档 | 说明书、文档中心 | [说明书交付](documents-delivery.md) |
| 检查进度、定位错误 | 生成任务、运行历史 | [任务与历史](generation-tasks-history.md) |

## 结果与产物

每个页面对应一种具体结果：规则、模型、测试用例或文档。**生成任务** 用于看当前进度，**运行历史** 用于查看过去的输入与结果。

## 映射关系

主要路径是 **需求文本 → 需求规则 → 需求模型 → 设计模型**。可行性分析从已确认规则开始；测试使用需求规则与用例模型；说明书汇总相应阶段的结果。

> [!NOTE]
> 图表位于 **需求模型**、**设计模型** 或 **可行性分析** 下。代码实现与运行验证在自己的开发环境中完成。

## 常见问题

**找不到某张图？** 展开对应阶段的菜单。若还未生成，先打开阶段首页查看生成卡片。

**不知道哪些内容需要重做？** 查看页面的 **需更新** 提示，再用 **链路图** 或 **跟踪矩阵** 找到受影响的来源与结果。

**只想完成课程文档？** 从[快速开始](quick-start.md)进入，按要交付的文档类型补齐产物即可。
