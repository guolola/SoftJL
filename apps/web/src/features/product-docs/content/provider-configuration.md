# 配置模型供应商

## 适用场景

使用自己的模型服务，或在开始生成前获取模型列表、测试连接并保存默认配置。界面中的 **Provider** 指模型供应商。

## 入口位置

右上角账号入口 → **账号设置 → 全局设置 → 模型托管配置**。

## 前置条件

- 已登录。
- 准备供应商提供的 **Base URL**（服务地址）和 **API Key**（密钥）。
- 供应商支持平台使用的 OpenAI 兼容接口，并有可用额度。

## 操作步骤

### 1. 添加供应商

点击 **添加供应商**，填写名称、Base URL 与 API Key。名称使用容易识别的描述即可。

![添加供应商：填写服务地址和密钥，再获取模型列表、测试并保存](/help/images/docs-provider-configuration.png)

### 2. 获取可用模型

点击 **获取模型列表**，等待连接与探测完成，再从列表选择 **供应商默认模型**。没有获取到可用模型时，先检查地址和密钥。

### 3. 测试并保存

点击 **测试托管配置**。通过后点击 **保存供应商**，返回全局设置再点击 **保存**，将其作为默认选择。

### 4. 在项目中确认

回到生成页面，核对当前供应商与模型，再用一小段需求开始生成。

> [!NOTE]
> 如果账号已有可用托管配置，可直接选择它并设置默认模型，无需重复添加供应商。

## 结果与产物

保存一份账号可用的供应商配置及默认模型。密钥不会在编辑界面回显；更换服务地址或密钥后，需要按提示重新获取模型并测试。

## 映射关系

供应商决定可选择的模型集合，模型调用费用由对应供应商账户结算。社区版不提供平台计费或生成额度。

## 常见问题

**保存按钮不可用？** 先获取模型列表、选择默认模型并通过连接测试。

**Base URL 填什么？** 使用供应商文档提供的服务根地址或兼容端点，避免把 API Key 填入地址或备注。

**模型名称找不到？** 默认模型必须来自当前供应商的可用目录，不能直接套用其他供应商的模型名称。

**已保存但生成仍失败？** 查看生成页实际选择，再核对供应商额度、模型状态和错误提示。参见[生成问题排查](troubleshooting.md)。
