# 创建与进入项目

## 适用场景

为一次课程实验或软件需求建立独立项目，或继续已有项目。

## 入口位置

打开[项目首页](/projects)，选择项目卡片，或点击 **新建项目**。

## 前置条件

已登录平台账号。新项目可以先保持未关联课程或团队；课程归属按账号可选范围设置。

## 操作步骤

项目首页集中展示可进入的项目。下图使用演示项目说明卡片与新建入口。

![当前项目首页：项目卡片与新建项目入口](/help/images/docs-project-home.png)

### 1. 填写基本信息

点击 **新建项目**，填写项目名称和描述，并选择项目背景。建议名称直接说明业务，例如“图书馆预约系统”；描述说明使用者和目标。

### 2. 选择范围与归属

点击 **下一步**，选择可见范围与课程、班级或团队归属。没有对应归属时，可保留未关联状态。

![创建项目第二步：选择可见范围；需要关联课程时再设置课程归属](/help/images/docs-project-create-scope.png)

### 3. 确认并进入

检查确认页中的名称、描述和可见范围，提交创建。进入工作台后，先打开左侧 **系统需求**。已有项目可直接从项目卡片进入。

> [!TIP]
> 项目描述用于识别项目。具体业务流程、规则和约束，请写在工作台的 **系统需求** 中。

## 结果与产物

项目会集中保存需求、分析、模型、测试用例、说明书和运行历史。返回项目后可以继续查看和处理这些内容。

## 映射关系

项目名称帮助你在列表和工作台辨认项目；课程与团队归属用于组织项目；成员角色决定可执行的操作。修改资料或邀请成员请阅读[项目设置与成员管理](project-drawers.md)。

## 常见问题

**项目列表为空？** 确认登录账号正确。若应由他人邀请加入，请让项目管理员检查成员或邀请状态；也可以新建自己的项目。

**下一步不可用？** 检查是否填写了项目名称。

**进入后不能编辑？** 查看当前成员角色，联系项目负责人调整权限。

**接下来做什么？** 阅读[快速开始](quick-start.md)，先生成并检查需求规则。
