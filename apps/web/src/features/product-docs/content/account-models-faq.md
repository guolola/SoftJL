# 账号、模型与权限问题

## 适用场景

遇到登录、项目访问、模型配置、账号安全问题，需要找到对应处理入口。

## 入口位置

- 右上角 **账号设置**：个人资料、安全设置、登录会话和全局设置。
- 项目侧栏 **项目管理 → 成员**：查看协作权限。

## 前置条件

先确认当前登录账号是否正确。项目邀请、权限、供应商配置和订单都与账号有关。

## 操作步骤

| 遇到的问题 | 先检查哪里 | 下一步 |
| --- | --- | --- |
| 无法进入项目 | 登录账号、成员或邀请状态 | 使用被邀请账号登录，或联系项目负责人 |
| 能查看但不能操作 | 当前成员角色、按钮提示 | 请负责人按实际职责调整权限 |
| 没有可用模型 | 全局设置中的供应商与目录 | 选择托管配置或[添加个人供应商](provider-configuration.md) |
| 模型连接失败 | 连接测试返回的错误 | 检查地址、密钥、模型与供应商额度 |
| 次数不足或订单未完成 | 账户账单 | 查看余额，或继续有效的待支付订单 |
| 需要管理登录设备 | 账号设置中的登录会话 | 核对设备与最近活动 |
| 需要启用验证码保护 | 安全设置中的 MFA | 按页面引导添加认证器并验证 |

![成员管理：先核对当前成员角色，再判断项目访问与操作权限](/help/images/docs-project-members.png)

## 结果与产物

你能确定问题属于账号、项目权限、模型服务还是账单，并在对应入口处理，避免在无关页面反复修改。

## 映射关系

登录会话决定账号身份；项目成员角色决定项目操作权限；模型配置决定调用哪个服务。它们需要分别检查。

## 常见问题

**列表中没有供应商？** 添加个人配置，或联系管理员确认托管配置是否对当前账号开放。

**测试通过但生成失败？** 查看实际任务的模型选择与错误；任务长度、额度和限流都可能影响结果。

**MFA 验证码无法通过？** 检查认证器条目与设备时间是否正确，再使用当前验证码。

**邀请后仍看不到项目？** 使用收到邀请的邮箱登录，确认邀请已接受且未失效。
