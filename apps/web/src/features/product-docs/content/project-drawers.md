# 项目设置与成员管理

## 适用场景

需要修改项目资料、邀请成员，或从工作台查看任务、历史和已生成文档。

## 入口位置

项目工作台左侧 **项目管理** 分组，包含 **链路图、运行历史、项目设置、成员、文档中心**。点击后在主内容区显示对应页面；小屏下先打开项目导航。

## 前置条件

当前账号是项目成员。具体管理操作由角色控制；按钮旁会说明权限不足的原因。

## 操作步骤

### 修改项目资料

打开 **项目设置**，修改名称、描述、背景、可见性、课程或团队归属，以及数据留存策略。检查内容后保存。

![项目资料与管理操作示例](/help/images/docs-project-settings.png)

### 邀请与管理成员

打开 **成员**，输入被邀请者邮箱并选择合适角色。已有邀请可查看状态，并按需要重发或撤销；成员角色可在权限允许时调整。

### 查找任务和文档

- **生成任务**：从顶栏任务状态入口查看正在排队或运行的内容、失败项和执行详情。
- **链路图**：查看跨阶段依赖关系，筛选节点并跳转到对应产物。
- **运行历史**：在主内容区查看历史记录；可执行的恢复、重试等操作以该记录提供的按钮为准。
- **文档中心**：查看说明书版本、下载和在线编辑状态。

### 使用链路图

各阶段从左向右排列，同阶段节点从上向下排列。卡片图标按规则类别、需求模型类型和设计模型类型区分；点击卡片才会展开节点详情。

悬停卡片后，第一个工具图标跳转对应页面（需求规则进入 **系统需求**），第二个生成或重新生成，第三个筛选影响路径。这三个工具图标不会自动展开详情。

卡片脚栏显示当前产物的生成人头像、生成耗时和节点状态。悬停头像查看姓名；没有头像时显示姓名缩写。模型耗时包含生成、修复和渲染；规则提示标明 **规则批次耗时**。新尝试运行或失败时，仍保留旧产物的生成信息。

多实例节点的脚栏代表最近更新的一张图，悬停耗时查看代表图名称，展开详情查看各实例的生成信息。

> [!WARNING]
> **项目设置** 中的归档、转移与删除会影响项目状态或归属。执行前先阅读确认提示，尤其要区分归档与删除。

## 结果与产物

保存后的项目资料用于辨认和管理项目；成员与邀请记录决定协作者的访问权限；文档中心保留生成的交付文件。

## 映射关系

这些入口都服务于当前项目。账号级模型配置位于 **账号设置 → 全局设置**，详见[账号与默认模型](account-global-settings.md)。

## 常见问题

**设置或成员操作不可用？** 检查成员角色与页面权限提示，再联系项目负责人。

**成员收不到邀请？** 核对邮箱和邀请状态，必要时重发。

**运行历史为空？** 先确认项目中是否已有生成记录。任务进度与历史操作见[生成任务与历史](generation-tasks-history.md)。

**脚栏显示“耗时未记录”或“生成人信息不可用”？** 历史记录缺少时间、不能可靠匹配当前产物版本，或生成人已无法从项目成员资料确定时，会显示信息缺失提示。未生成的节点显示 **未生成**，不会估算耗时。
