# 说明书生成与下载

## 适用场景

将项目已有需求与模型汇总成可提交的 DOCX，调整排版、查看版本或在线编辑。

## 入口位置

左侧 **说明书** 负责生成；左侧 **项目管理 → 文档中心** 负责查找已保存文件和版本。

## 前置条件

| 文档类型 | 先准备什么 |
| --- | --- |
| 需求规格说明书 | 当前需求规则与所需需求模型 |
| 软件设计说明书 | 所需设计模型及其来源 |
| 可行性研究报告 | 当前有效的系统环境图、业务与系统流程图和实现方案 |

具体缺失项以所选文档旁的提示为准。配图需要已有成功渲染的图表。

## 操作步骤

### 1. 选择文档类型

打开 **说明书**，选择要生成的文档，先处理缺失或需更新的产物。

![说明书入口：选择文档类型；灰色按钮表示仍需补齐该文档的前置产物](/help/images/docs-documents.png)

### 2. 设置排版

打开 **说明书样式**，按需要调整目录、标题编号、字体、字号、行距与表格样式。也可以使用默认课程设计规范。

### 3. 生成并检查

发起生成，在 **生成任务** 查看进度。完成后检查正文、配图、引用和缺图提示，确认内容对应当前项目。

### 4. 下载与管理版本

在当前页面或 **文档中心** 下载文件、查看版本。页面提供在线编辑入口时，可使用 OnlyOffice 编辑；注意文件状态与编辑锁提示。

> [!WARNING]
> 文档保留生成时的内容。后续修改需求、模型或方案后，应重新生成并检查需要交付的版本。

## 结果与产物

获得可下载的 DOCX 和文档版本记录。交付前确认所选版本正确、下载可用、配图与正文一致。

## 映射关系

需求规则对应需求条目；模型和 SVG 对应图表章节；追踪关系解释来源；设计模型提供架构、类与数据库内容；可行性分析提供方案、成本、风险与结论。

## 常见问题

**说明书缺图？** 返回对应模型页检查图片是否成功渲染，补齐后重新生成文档。

**可行性报告无法生成？** 按提示更新两张前置图或实现方案。方案只使用旧流程时，需要重新生成，不能仅保存文字修改。

**找不到下载或编辑入口？** 查看文档中心的文件状态与当前权限；在线编辑还取决于服务是否可用。

**版本太多？** 核对生成时间和内容，确认需要交付的版本后再下载。
