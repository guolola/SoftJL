# 账号设置与默认模型

## 适用场景

修改个人资料、管理登录安全，或为生成任务设置默认供应商与模型。

## 入口位置

点击右上角账号入口，打开 **账号设置 → 全局设置**。

## 前置条件

已登录。设置默认模型前，账号需要有可用的托管配置，或已添加个人供应商。

## 操作步骤

1. 打开 **全局设置**，找到 **模型托管配置**。
2. 在 **托管 Provider 配置** 中选择供应商。
3. 从该供应商返回的列表中选择 **默认模型**。
4. 点击 **测试托管配置**，确认连接结果。
5. 保存设置，再回到生成页面检查当前选择的供应商和模型。

若要添加自己的服务，继续阅读[配置模型供应商](provider-configuration.md)。

![全局设置：选择托管 Provider 配置和默认模型，测试后保存](/help/images/docs-account-global-settings.png)

## 结果与产物

保存后，所选配置成为生成时可使用的默认选择。工作台偏好控制界面显示；个人资料、安全设置和登录会话分别管理账号信息与访问安全。

## 映射关系

**供应商** 提供可用模型和调用额度；**默认模型** 是生成任务的初始选择；实际使用哪一个，以生成页面的当前选择和运行记录为准。

> [!TIP]
> 先用一小段需求验证连接和结果，再启动完整模型或长文档生成。选型方法见[模型选择指南](recommended-models.md)。

## 常见问题

**供应商列表为空？** 可以添加个人供应商，或联系管理员确认账号是否有托管配置权限。

**模型列表为空？** 确认已选供应商。个人供应商可重新获取模型列表；托管配置可联系管理员刷新目录。

**测试失败？** 按错误提示检查供应商地址、模型可用性、余额或网络状态。详见[账号与权限问题](account-models-faq.md)。
