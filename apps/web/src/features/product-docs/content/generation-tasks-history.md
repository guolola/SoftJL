# 查看生成任务与运行历史

## 适用场景

检查生成到哪一步、定位失败项，或找回以前的输入与结果。

## 入口位置

项目工作台顶部的任务状态入口打开 **生成任务** 抽屉；左侧 **项目管理 → 运行历史** 打开历史页面。

## 前置条件

项目中已经发起过生成。历史记录可用的操作取决于记录类型与保存的内容。

## 操作步骤

### 生成期间查看任务

打开 **生成任务**，先看任务状态，再展开具体阶段和子任务。排队提示会说明当前等待原因；失败项可查看错误，并在提供重试操作时重试。

![生成任务抽屉：展开具体任务，检查阶段状态和输出](/help/images/docs-generation-tasks.png)

### 生成后查看历史

打开 **运行历史**，按时间和任务类型找到记录，核对生成模型、状态与输入输出。需要恢复时，先确认记录属于当前项目及目标阶段，再使用该记录提供的恢复操作。

> [!WARNING]
> 恢复快照会改变工作台当前显示的阶段内容。先核对记录时间和结果，避免把历史结果当成最新需求的输出。

![运行历史：按类型与状态查找记录，核对时间后再决定重跑或恢复快照](/help/images/docs-run-history.png)

## 结果与产物

| 位置 | 主要用途 |
| --- | --- |
| 生成任务 | 查看排队、运行、完成、失败与可重试项 |
| 运行历史 | 核对历史输入、结果、状态和可用操作 |
| 对应阶段页面 | 检查生成后的模型、图表或文档 |

## 映射关系

需求抽取对应 **系统需求**；环境图、流程图与方案对应 **可行性分析**；模型、图源码与图片对应 **需求模型** 或 **设计模型**；文档生成对应 **说明书**。


## 常见问题

**一直在排队？** 查看任务中的队列原因，可能是服务器或供应商繁忙、项目或账号并发已满。

**只有一张图失败？** 找到该子任务并重试；无需重新生成已成功的全部内容。

**恢复后仍提示需更新？** 历史结果可能基于旧需求。按当前页面的上游状态决定是否重新生成。

**错误看不懂？** 先确定失败阶段，再按[生成问题排查](troubleshooting.md)处理。
